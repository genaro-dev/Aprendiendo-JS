Lección 1

Variables: const y let

Una variable es una caja con nombre donde guardás un valor para usarlo después. En JavaScript moderno se declaran con dos palabras:

const — constante

No se puede reasignar. Usala por defecto: casi todo lo que guardás no cambia de caja.

let — variable

Se puede reasignar. Usala cuando el valor va a cambiar: contadores, totales, estados.

Existe también var, la forma vieja. Tiene reglas raras de alcance y hoy no se recomienda.

Dos detalles importantes

Alcance de bloque. Una variable declarada dentro de { } (un if, una función, un bucle) solo existe ahí adentro.

const no congela objetos. Impide cambiar qué caja es, pero si adentro hay un objeto o un array, sus contenidos sí se pueden modificar.

Para armar textos con variables usá template literals: comillas invertidas y ${ }.

Ejemplo — ejecutalo y modificalo

Regla práctica: escribí siempre const. Si después necesitás reasignar, cambialo por let.

Tarea 1 El carrito

Declará precio (1200, no cambia) y cantidad (empieza en 1). Sumale 2 a la cantidad y mostrá en consola: Total: $3600 (3 unidades) usando un template literal.

Ver pista

¿Cuál de las dos cambia? Esa va con let. Para sumar: cantidad = cantidad + 2 o cantidad += 2.

Ver solución
const precio = 1200;
let cantidad = 1;
cantidad += 2;
const total = precio * cantidad;
console.log(`Total: $${total} (${cantidad} unidades)`);
Lección 2

Funciones e if

Una función es un bloque de código con nombre que podés ejecutar cuantas veces quieras. Recibe datos (parámetros) y puede devolver un resultado con return. Cuando llega a return, la función termina.

// Declaración clásica
function sumar(a, b) {
  return a + b;
}

// Función flecha (arrow function): lo mismo, más corto
const restar = (a, b) => a - b;

sumar(2, 3);   // 5
restar(9, 4);  // 5

El if decide qué camino seguir según una condición que da true o false. Podés encadenar casos con else if y dejar un else final para “todo lo demás”.

Comparar

=== igual · !== distinto · > < >= <=

Combinar

&& y · || o · ! negación

Usá === y no ==. El triple igual compara valor y tipo: 5 === "5" es false, mientras que 5 == "5" da true y trae sorpresas.

Ejemplo

Tarea 2 Precio final

Escribí una función precioFinal(precio, esSocio): si es socio, hace 10% de descuento. Además, si el precio (ya con descuento) es menor a 5000, suma 800 de envío. Probala con (10000, true) → 9000, (4000, false) → 4800 y (5000, true) → 5300.

Ver pista

Usá let para el precio que vas modificando. Primero el descuento (* 0.9), después el envío. Son dos if separados, no un else if, porque pueden pasar las dos cosas.

Ver solución
function precioFinal(precio, esSocio) {
  let total = precio;
  if (esSocio) {
    total = total * 0.9;
  }
  if (total < 5000) {
    total = total + 800;
  }
  return total;
}
Lección 3

document.querySelector y addEventListener

El navegador convierte el HTML en un árbol de objetos llamado DOM. Con JavaScript podés buscar cualquier elemento de ese árbol y reaccionar cuando el usuario hace algo.

Buscar elementos

document.querySelector(selector) devuelve el primer elemento que coincide con un selector CSS, o null si no hay ninguno. querySelectorAll devuelve todos, en una lista (NodeList) que podés recorrer con forEach.

document.querySelector("#mensaje")   // por id      →  <p id="mensaje">
document.querySelector(".fruta")     // por clase   →  la primera .fruta
document.querySelector("button")     // por etiqueta
document.querySelectorAll(".fruta")  // todas las .fruta

Escuchar eventos

elemento.addEventListener("evento", función) le dice al navegador: “cuando pase esto, ejecutá esta función”. Los eventos más comunes: click, input, submit, keydown, mouseover. La función recibe un objeto evento con datos de lo que pasó, por ejemplo evento.target: el elemento que lo disparó.

Pasá la función sin paréntesis: boton.addEventListener("click", saludar). Si escribís saludar(), se ejecuta en el momento y no al hacer clic.

Ver solución
const frutas = document.querySelectorAll(".fruta");
console.log("Hay", frutas.length, "frutas");

frutas.forEach((fruta) => {
  fruta.addEventListener("click", () => {
    console.log(`Elegiste: ${fruta.textContent}`);
  });
});
Lección 4

Cambiar texto y clases

Una vez que tenés un elemento, podés cambiar lo que dice y cómo se ve.

textContent

Lee o reemplaza el texto. Lo que pongas se muestra tal cual, nunca se interpreta como HTML. Es la opción segura.

innerHTML

Reemplaza el contenido interpretándolo como HTML. Útil para armar estructura, peligroso con texto que escribió un usuario (puede inyectar código).

Para el aspecto, lo ideal es no tocar estilos uno por uno sino agregar o quitar clases definidas en el CSS. Para eso está classList:

el.classList.add("activa")        // agrega
el.classList.remove("activa")     // quita
el.classList.toggle("activa")     // si la tiene la quita, si no la agrega
el.classList.contains("activa")   // true o false

Tarea 4 Interruptor de modo

Hacé que el botón #btn-modo alterne la clase oscura en la tarjeta. Además, su texto tiene que decir Modo claro cuando la tarjeta está oscura y Modo oscuro cuando no.

Ver pista

Dentro del listener: primero toggle, después preguntá con contains y usá un if para decidir el texto.

Ver solución
const tarjeta = document.querySelector("#tarjeta");
const boton = document.querySelector("#btn-modo");

boton.addEventListener("click", () => {
  tarjeta.classList.toggle("oscura");
  if (tarjeta.classList.contains("oscura")) {
    boton.textContent = "Modo claro";
  } else {
    boton.textContent = "Modo oscuro";
  }
});
Lección 5

fetch y JSON (concepto)

Muchas páginas piden datos a un servidor sin recargarse: el clima, una lista de productos, tus mensajes. Para eso se usa fetch. Y casi siempre esos datos viajan en formato JSON.

JSON

JSON (JavaScript Object Notation) es texto con forma de objeto. Las claves van siempre entre comillas dobles; no admite comentarios ni funciones.

{ "nombre": "Ana", "edad": 30, "cursos": ["JS", "CSS"], "activo": true }
JSON.parse(texto)

Texto JSON → objeto de JavaScript.

JSON.stringify(objeto)

Objeto de JavaScript → texto JSON, listo para enviar o guardar.

Cómo funciona fetch

Pedir algo por internet tarda. Por eso fetch no te da los datos al instante: devuelve una Promise, una promesa de que la respuesta va a llegar. Con await (dentro de una función async) esperás a que se cumpla. El proceso tiene dos pasos:

  1. await fetch(url) → llega la respuesta (estado, encabezados…).
  2. await respuesta.json() → se lee el cuerpo y se convierte en objeto.
Un 404 o un 500 no hace fallar a fetch: la promesa solo se rechaza si no hay conexión. Para saber si salió bien, mirá respuesta.ok (true si el estado está entre 200 y 299).

Existe otra forma de escribirlo, con .then(), que vas a ver mucho en internet. Hace exactamente lo mismo:

fetch("/api/usuario/1")
  .then((respuesta) => respuesta.json())
  .then((datos) => console.log(datos))
  .catch((error) => console.error("Falló:", error));

Tarea 5 Lista de productos

Pedí /api/productos. Si la respuesta no es ok, mostrá un console.error. Si es ok, mostralos con console.table y después el precio total. Bonus: envolvelo en try/catch y probá cambiar la URL por /api/nada.

Ver pista

Los productos llegan como un array de objetos con nombre y precio. Para el total podés recorrerlo con forEach sumando a una variable let.

Ver solución
async function cargarProductos() {
  try {
    const respuesta = await fetch("/api/productos");
    if (!respuesta.ok) {
      console.error("Error del servidor:", respuesta.status);
      return;
    }
    const productos = await respuesta.json();
    console.table(productos);

    let total = 0;
    productos.forEach((p) => { total += p.precio; });
    console.log(`Total: $${total}`);
  } catch (error) {
    console.error("Sin conexión:", error.message);
  }
}
Lección 6

La consola del navegador

Todos los navegadores traen herramientas para desarrolladores. La pestaña Console es donde ves los mensajes de tu código, los errores y donde podés escribir JavaScript directo sobre la página abierta, como en la consola de arriba de todo.

Abrirla

F12 o Ctrl+Shift+J en Windows/Linux · Cmd+Option+J en Mac (Chrome). También: clic derecho → Inspeccionar → Console.

Usarla

Escribís una expresión, Enter, y ves el resultado. Con la flecha ↑ recuperás lo último que escribiste.

Los métodos que más vas a usar

console.log("info general", variable)
console.warn("advertencia")      // amarillo
console.error("algo salió mal")  // rojo
console.table(arrayDeObjetos)    // lo muestra como tabla

Leer un error

Un error en rojo te dice qué tipo de error es, un mensaje y en qué archivo y línea ocurrió. Los tres más comunes al empezar:

ReferenceError

Usaste una variable que no existe: un typo o algo fuera de su bloque.

TypeError

Hiciste algo que ese valor no admite: reasignar un const, o usar .textContent sobre null porque el querySelector no encontró nada.

SyntaxError

El código está mal escrito: falta un paréntesis, una llave o una comilla.
